# B08A01

## First Assignment: TypeScript Fundamentals

This repository contains the completed first assignment for learning and practicing core TypeScript concepts.

### Assignment Overview
The goal of this assignment was to understand and apply essential TypeScript features used in real-world code, including:

- type narrowing
- union types
- generics
- interfaces and object modeling
- classes and inheritance
- async functions and Promises

### Files Included

- [solutions.ts](./solutions.ts) — practical TypeScript examples and coding exercises
- [type-narrowing.md](./type-narrowing.md) — explanation of narrowing with `typeof`, `instanceof`, and `in`
- [type-vs-interface.md](./type-vs-interface.md) — comparison between `type` aliases and `interface`

### What I Learned

- How TypeScript narrows types safely inside conditional logic
- How to work with union and primitive types effectively
- How to create reusable code with generics
- When to use `interface` versus `type`
- How classes and inheritance work in TypeScript
- How async logic can be handled with Promises
